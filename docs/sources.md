# Источники и происхождение

Портфолио собрано из учебных работ Антона Чуркина. При оформлении сохранено различие между исходной задачей, используемыми готовыми моделями, кодом решения и проверкой результата. Репозиторий не заявляет авторство исходных датасетов, архитектур или учебных постановок.

- Компьютерное зрение: [исходный Itmo2026Cv](https://github.com/Xokage9/Itmo2026Cv/tree/db1168a6fbadfdf459efc8654055062e5f908746); зафиксирован commit `db1168a6fbadfdf459efc8654055062e5f908746`. В README проектов указаны исходные имена ноутбуков через `recorded_metrics.json`.
- RAG, графовый поиск и детекция заправок: текущие версии учебных ноутбуков, использованные при подготовке 18 ноября 2026 года. Для топливной задачи исходные данные и постановка: [hehehelp123/fuel-refuel-lab](https://github.com/hehehelp123/fuel-refuel-lab).
- Корпус публикаций: [arXiv API](https://info.arxiv.org/help/api/index.html). Названия, аннотации и авторы сохраняются вместе со ссылками на публикации.
- Номера домов: [Stanford SVHN](http://ufldl.stanford.edu/housenumbers/).
- Детекция: [Ultralytics](https://github.com/ultralytics/ultralytics), [формат набора данных](https://docs.ultralytics.com/datasets/detect/). У пакета и моделей собственные условия лицензирования.
- Сегментация и классификация: [TorchVision](https://github.com/pytorch/vision), [timm](https://github.com/huggingface/pytorch-image-models).
- Эмбеддинги и генерация: модели, идентификаторы которых указаны в ноутбуке RAG; их model cards и условия использования доступны на Hugging Face.

Исходные данные и веса устанавливаются отдельно по инструкциям проектов. Для сторонних компонентов действуют их собственные лицензии.
