# Отбор лабораторных

Работы оценены по объёму самостоятельной логики, сложности подготовки данных, устройству модели, проверке результата и пригодности к воспроизведению. Номер лабораторной и длина файла сами по себе не определяют сложность. Дубликаты и ранние версии рассмотрены как одна задача.

| Работа | Решение | Основание |
|---|---|---|
| RAG по научным статьям | Включена | Поиск, генерация, проверка утверждений, два разбиения корпуса |
| Детекция заправок | Включена | Временные ряды, сравнение конфигураций, разделение машин, событийный F1 |
| SVHN / YOLO | Включена | Конвертация сложной разметки и обучение детектора; разбиение исправлено |
| Сегментация дорожных знаков | Включена | Подготовка масок, fine-tuning, оценка; бинарная метрика явно названа |
| Цвет автомобилей / transfer learning | Включена | Три подхода, дисбаланс классов и анализ Macro-F1 |
| Графы научных публикаций | Включена | Корпус, извлечение терминов, сообщества и поисковые эксперименты |
| MLP и CNN на MNIST (`lab3`) | Не включена в витрину | Полезный базовый эксперимент, но менее сложный по данным и постановке |
| Операции с изображениями (`lab1`, `lab2`) | Не включены в витрину | Фильтры, цветовые модели и базовые преобразования; приоритет отдан обучаемым системам |
| GAN / cGAN (`la7`) | Требует доработки | В конце есть метрики с `source=mock_baseline`; присутствуют дубли классов и несогласованные размерности |
| Diffusion / LoRA (`lab8`) | Требует доработки | Есть прерванная ячейка; нужна отдельная проверка полного запуска и совместимости библиотек |
| Рекомендации VK-LSVD | Следующий кандидат | Содержательная реализация MostPop, ItemKNN, EASE и ALS; нет сохранённого завершённого итогового сравнения |
| ЭЭГ SEED | Резерв | Реализованы признаки и разделение по участникам; исходный набор требует отдельного доступа |
| Регрессия по RGB | Резерв | Интересен групповой протокол, но Ridge на сохранённом тесте хуже среднего baseline |
| Дыхание по видео | Требует натурного эксперимента | Сохранена синтетическая проверка; собственное видео и ручной эталон отсутствуют |
| Личностные признаки / Kassab | Резерв | Сопоставление источников и несколько моделей, но всего 38 участников |
| Sample-ML-Repo | Учебные материалы | Fork учебного курса; не представлен как отдельный авторский проект |
| `lab7.ipynb` | Исключён | Пустой файл; рабочий вариант лежит в `la7.ipynb` |

Просмотрены доступные ноутбуки из `Itmo2026Cv`, текущие учебные файлы и архив ML_Labs. Закрытые источники, которые не удалось прочитать, в отбор не включены.
