# Сегментация дорожных знаков

[← Все проекты](../../README.md) · [Ноутбук](notebook.ipynb) · [Открыть в Colab](https://colab.research.google.com/github/Xokage9/ml-portfolio/blob/main/projects/04_segmentation/notebook.ipynb)

Обучить DeepLabV3 ResNet50 выделять дорожные знаки и сравнить предсказания с эталонными масками.

## Что реализовано

Конвертация масок в полигоны, выбор восьми классов по train, растеризация меток, AMP, накопление градиентов и сохранение лучшей модели.

## Данные

Рядом с ноутбуком нужен `sign_dataset/images/{train,val}/` и `sign_dataset/labels/{train,val}/`. Метки — нормализованные YOLO-полигоны; ячейка конвертации также поддерживает локальные `*_coco.json` с `class_ids` и `masks`. Каталог необязательных фотографий — `test_images_lab6/`.

## Запуск

Из корня репозитория выполните:

```bash
python -m pip install -r projects/04_segmentation/requirements.txt jupyterlab
cd projects/04_segmentation
python -m jupyter lab notebook.ipynb
```

В Colab откройте ссылку выше, выполните ячейку установки и разместите исходные данные в рабочем каталоге. Для полного обучения и генерации нужен подходящий GPU; подготовка данных и часть анализа работают на CPU. Зависимости заданы диапазонами, это не lock-файл конкретного CUDA-окружения.

## Проверка качества

Модель предсказывает восемь классов и фон. Итоговый отчёт исходного эксперимента объединяет все знаки в foreground и считает бинарные метрики; mean foreground IoU нельзя называть многоклассовым mIoU.

## Зафиксированный результат

Сохранённая validation: mean foreground IoU 0.8657; precision 0.8753; recall 0.9898.

Данные взяты из сохранённых выводов исходной работы. Полный запуск обновлённой версии на GPU не выполнялся. Метрики нового запуска должны сохраняться отдельно от [истории эксперимента](results/recorded_metrics.json).

## Ограничения

Это validation, используемая при выборе checkpoint. Фотографии без ручных масок дают только визуальные примеры. После исправления обработки пустых масок и усреднения оценку необходимо пересчитать.
